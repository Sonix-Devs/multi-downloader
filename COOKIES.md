# Cookies & Local Storage — Multi Downloader

_Last updated: 2026_

## No tracking cookies

Multi Downloader does not use advertising or analytics cookies. There are no
third-party trackers, pixels, or fingerprinting scripts embedded in the app.

## Functional storage only

The app persists your preferences (theme, default save folder, default
quality, concurrency limit, etc.) and your download history in a local
database so the app remembers your setup between sessions. This data never
leaves the machine running the app.

## Browser storage

The web UI may use `localStorage`/`sessionStorage` purely for ephemeral UI
state (e.g. remembering a dismissed clipboard suggestion during a session).
None of this is used for tracking or shared with third parties.
